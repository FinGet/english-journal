# 系列封面制作

本页完整定义Journal的3:4封面母版、中文主题提炼、真实人物选帧、去背景剪贴与纸张层次，无需读取其他项目或寻找外部母版。Journal使用青绿赤陶色板、Z、账号名和slogan，不引入纠错内容。排版和文字由Remotion控制，人物抠图作为本期素材接入，后续期数不重新生成整张母版。

## 固定与可变内容

- 比例固定3:4，逻辑尺寸1080×1440，默认封面scale=1；通过project.config.json管理，独立于9:16视频。
- 固定：浅灰绿底#f4f6f3、深青绿主文字#173d3a、赤陶强调#a85134、Outfit与中文黑体、Z、张木示、账号下方完整slogan、系列标识和期号位置。色值统一读取brand.config.json。背景使用双层网格、细纸纹与浅色大Z水印；上方放大系列字标SPEAKING / PRACTICE，明确口语练习定位，顶部保留ENGLISH SPEAKING JOURNAL；中部左侧中文主题配半透明标记，下方英文副题使用倾斜撕纸与胶带。人物使用浅色剪贴轮廓与柔和阴影。
- 每期只改变期号、一至三行中文主题、可选英文副题和实际人物抠图。中文主题每行最多八字符，概括整期主线；用户给出的主题优先，不用支线替代全片，不夸大观点。
- 第一张经用户确认的Journal封面作为系列母版保留，后续参照它保持字阶、间距、人物比例和留白。

## 构图与人物边沿（2026-11-18修订）

按用户提供的Coach封面参考，Journal改用更饱满的海报层次：顶部账号与完整slogan、右侧期号；放大的系列字标占据上半部；中文主题在中部左侧；英文副题在左下纸条；大人物贴右下边沿。只借鉴构图关系，品牌、文字和素材由本项目独立管理。

人物默认宽840px、等比自动高度，右移至right=-130px，底边bottom=-80px。整个透明PNG完整参与排版，不使用固定宽高框、object-fit:cover、局部蒙版或容器裁切头肩；画面外部分由1080×1440封面边界自然裁切。三行标题也不自动缩小人物。浅色剪贴边与阴影沿真实轮廓添加，不为人物再画一个矩形边框。不补造原片里没有的身体。

当期抠图长宽比或透明留边不同时，可在cover里设置portraitBottom（逻辑像素，整数-360至0，默认-80）调整人物贴底位置，保持原图等比与840px宽度，不修改其他期数。EP11使用-220，让这张较高的真实人物PNG下移，留出系列字标位置；仍只由封面边沿自然裁切，不能通过此字段遮住眼睛或裁掉头部。

系列字标按首词与后续词组分两行，默认大字阶并根据每行长度收放；中文主题左栏约480px，短标题可到128px，按中英字符宽度估算缩放。长题优先提炼、断行；最多三行、每行最多八字符的内容约束继续适用，不靠把人物缩成小图腾空间。副题纸条随中文行数下移，不覆盖脸；不重复加系列名或无关文案填空。

放大的系列字标、中文主题、人物、撕纸与网格共同形成密度。纸张层次包括淡赤陶底纸、主纸条、细边与短胶带；保留品牌青绿赤陶，避免照搬Coach的荧光绿或纠错内容。版式修改后按常规流程预览并审查；实际审查与渲染记录以本期工作文件为准。

## 中文主题提炼

先读完整口播，写出“这期在讲什么”和“说话者最强烈的真实感受/冲突是什么”，再合成一句有态度、有情绪的中文标题。优先采用口播中的生动说法、经历中的反差或明确感受，让观众感受到这期为什么值得听；不要只给出像知识提纲一样的中性总结。

EP10按用户指定使用“AI 蠢到让人抓狂”，排成“AI 蠢到 / 让人抓狂”，依据是使用AI剪辑带来的挫败和口播里的driving me crazy。标题保留整期关于AI局限的主线，从真实情绪进入。用户提供的文案优先保留，只调整断行；英文副题如保留，应呼应同一情绪。

情绪随内容而变，可以是抓狂、惊喜、遗憾、期待或反差，不固定套用愤怒口吻。不添加未发生的经历、赛事结果或更极端的立场，不凭一个孤立片段歪曲整期。将标题、对应原话与情绪依据记录在本期导演方案或封面制作记录里。

## 人物选帧

先根据实际原声找非说话停顿，再考虑一个词刚结束的位置。字幕空档不是静音证据。优先自然、放松、略带笑意的表情；正脸或自然约45°侧脸均可，不强制直视镜头、闭嘴或重新摆姿。

选帧时查看候选前后连续帧，排除眨眼、发音中途、准备发音时夸张口型、遮挡与透视畸变；双眼睁开、五官完整、比例正常。保留真实身份、发型、衣服和选定头部角度，不重绘或美化出另一张脸。

agent完成候选比较和真实人物审查，记录选帧依据；有具体身份或表情疑点才请用户判断，不把每张候选变成审批步骤。候选和依据放work/covers/；已有用户认可的本期人物形象可复用。

## 人物抠图

制作一期包含人物选帧、候选前后对照、去背景、成图预览和正式封面导出，默认执行，不另设暂停。历史EP10曾沿用frame2840候选，只是该期记录，不能成为新期数固定选帧或等待确认的规则。

优先复用本期已有准确透明人物图；需新抠图时使用可用图片编辑工具，先读对应skill。输入必须是本期真实人物参考；仅去除房间背景，保留发丝、眼镜、脸部比例、皮肤、表情、视线、头部角度和服装，不美化重画，不补造未拍到的身体。输出需真正alpha透明，不能把白底图片当成透明抠图。

透明PNG存public/epXX/<edition>/cover/，参考帧、实际提示词、成片哈希/帧号与生成记录存本期work/covers/；保留原图。人物白边与阴影由母版统一添加，素材本身不烘焙标题、纸张背景或边框。图片工具的保真约束不能替代实际审查；agent对照真实参考检查身份、表情及边缘，再记录审查结果。具体疑点无法判定时才请用户确认。

## 数据与浏览器预览

每期motion.json中的cover示例：

```json
{
  "cover": {
    "frame": 120,
    "title": ["先学会倾听", "再学会表达"],
    "subtitle": "LISTEN FIRST. SPEAK WITH INTENT.",
    "portrait": "ep11/journal/cover/portrait-cutout.png",
    "status": "draft",
    "note": "Candidate from a real pause; review identity, expression, headline and layout before marking approved."
  }
}
```

frame记录人物参考来自成片program的哪一帧（30fps），不是原片秒数，不得引用片尾三连；portrait是对应人物的本地透明PNG路径。更换参考帧时要同步重做/替换人物素材和记录，不能只改frame假装人物已更新。每行中文主题最多八字符、最多三行，英文副题可省略。当前候选不等于已经选定。

在Remotion Studio选JournalCover，可直接看同一份封面配置。封面使用独立构图和透明人物图，不把9:16视频机械裁成3:4，也不回退到矩形视频截图。缺少人物素材时展示草稿占位，最终导出会拦截尚未完成质量审查的封面或未准备的人物图。

完成真实人物、主题和版式审查后，由制作方如实将cover.status记录为approved；原话也须已核对，封面不要求整片动效先完成。approved是质量记录，不是额外的用户许可开关。随后直接运行：

```sh
npm run cover -- --episode 11 --edition journal
```

输出output/epXX/cover.png，旧版先备份到本期work/previous-exports；参考帧、实际标题、来源和候选放work/covers/。视频scale=2不会把封面默认也放大两倍，封面scale单独控制。

## 制作审查点

账号与slogan完整、期号正确、主题准确、三行以内、缩略图可读；人物自然且身份不变，足够大且紧贴右下边沿，只由封面边界裁切；文字不挡脸，核心文字留有余量，人物无需四周留白；背景纸张、网格与字阶形成饱满层次，画风与已确认系列母版一致。这些检查由agent在常规制作中完成，并保留实际证据；用户反馈继续优先采用。
